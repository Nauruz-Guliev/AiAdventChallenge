# AI Advent Challenge

Небольшие проекты для изучения LLM API.

## Дни

- [`day1`](./day1) — веб-чат с OpenCode-совместимым LLM API.
- [`day2`](./day2) — наглядное сравнение обычного ответа и ответа с ограничениями формата, длины и завершения.
- [`day3`](./day3) — сравнение четырёх способов рассуждения на одной логической задаче с автоматической проверкой точности.
- [`day4`](./day4) — сравнение одного творческого запроса при temperature `0`, `0.7` и `1.2`.
- [`day5`](./day5) — сравнение одного аналитического запроса на слабой, средней и сильной модели с замером времени, токенов и reference-стоимости.
- [`day6`](./day6) — первый отдельный Python-агент с FastAPI, DeepSeek API и React-интерфейсом, показывающим поток запроса.
- [`day7`](./day7) — сохранение контекста: история чатов в JSON переживает перезапуск, интерфейс показывает список чатов.
- [`day8`](./day8) — подсчёт токенов и лимит контекста: запрос/история/ответ, накопительная стоимость и переполнение бюджета.
- [`day9`](./day9) — управление контекстом: rolling-summary вместо старой части истории, тумблер сжатия и сравнение качества/токенов.
- [`day10`](./day10) — стратегии контекста: sliding window, sticky facts и ветвление с автосравнением на одном сценарии.
- [`day11`](./day11) — модель памяти ассистента: краткосрочная, рабочая и долговременная память хранятся раздельно.

Каждый день является отдельным проектом и содержит собственную инструкцию по запуску.
