# День 24 — Цитаты, источники и анти-галлюцинации

Дорабатываем RAG из Дня 23 так, чтобы модель **обязательно** возвращала:

- **ответ**;
- **список источников** (source + section + chunk_id);
- **цитаты** — дословные фрагменты из найденных чанков.

И добавляем правило анти-галлюцинаций: если релевантность ниже порога — ассистент
говорит «не знаю» и просит уточнение.

Один вопрос — **три режима**, и на 10 контрольных вопросах проверяем три вещи:
есть ли источники, есть ли цитаты, совпадает ли смысл ответа с цитатами.

Стек: FastAPI (backend) + React/Vite (frontend), LLM — DeepSeek API.

## Как это работает

```
вопрос → [rewrite] → поиск → (rag_guard: фильтр + реранк) → контекст → LLM
       → парсинг маркеров [n] → цитаты (дословные фрагменты чанков)
```

- Индекс — из Дня 21: `day21/index/structure.json` (4817 чанков).
- Эмбеддинги — `paraphrase-multilingual-MiniLM-L12-v2`.
- LLM помечает каждый факт маркером `[n]` (номер блока контекста).
- Backend для каждого маркера находит **самую длинную общую подстроку** (LCS) между
  ответом и текстом чанка — это и есть «цитата», дословный фрагмент чанка.
- Цитата считается **grounded**, если её длина ≥ `MIN_QUOTE_LEN` (24 символа).
- Правило «не знаю»: релевантность = cosine-сходство **оригинального** вопроса с лучшим
  найденным чанком; если оно ниже `NO_ANSWER_MIN_SCORE` (0.60) — ответ «не знаю».

## Три режима

| Режим | Rewrite + фильтр + реранк | Цитаты | «Не знаю» |
|---|---|---|---|
| `no_rag` | — | — | — |
| `rag` | — | да | — |
| `rag_guard` | да | да | да |

## Установка и запуск

Все команды — в PowerShell. Backend и frontend в двух окнах.

### 1. Backend

```powershell
cd day24/backend
python -m venv .venv
& .venv/Scripts/python.exe -m pip install -r requirements.txt

copy .env.example .env
# открой .env и впиши DEEPSEEK_API_KEY

& .venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Нужен индекс Дня 21. Если его нет — собери:

```powershell
cd ../day21
& .venv/Scripts/python.exe pipeline.py --strategy both --embedder sentence
```

### 2. Frontend

```powershell
cd day24/frontend
npm install
npm run dev
```

Открой http://localhost:5173 — вкладка «Вопрос» (три режима с цитатами) и
«Сравнение режимов».

### Офлайн-режим (без ключа)

В `.env` поставь `LLM_PROVIDER=fake` — ответы даёт детерминированная заглушка.

## Настройки (.env)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `MIN_QUOTE_LEN` | 24 | мин. длина дословной цитаты |
| `NO_ANSWER_MIN_SCORE` | 0.60 | порог релевантности для «не знаю» |
| `MIN_SIM` | 0.35 | cosine-порог фильтра (rag_guard) |
| `K_PRE` / `K_POST` | 30 / 8 | top-k до/после фильтра |

## API

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/api/answer` | `{question}` → ответы 3 режимов + источники + цитаты + `answerable`/`relevance` |
| GET | `/api/questions` | список 10 контрольных вопросов |
| POST | `/api/eval` | прогон 10 вопросов по 3 режимам, пишет `data/eval_report.json` (кэш; `?force=1` — пересчёт) |

## Результаты реального прогона

Средние по 10 вопросам (DeepSeek-судья):

| Режим | Балл | Покрытие | Цитаты (rate) | Grounding | Support | «Не знаю» |
|---|---|---|---|---|---|---|
| без RAG | **0.98** | — | 0.0 | 0.0 | 0.0 | 0.0 |
| RAG | **0.76** | 0.80 | **1.0** | **0.50** | **0.87** | 0.0 |
| RAG Guard | **0.51** | 0.80 | **0.70** | **0.28** | **0.77** | **0.20** |

- **Источники есть** в каждом RAG-ответе (coverage 0.80, как в Дне 23).
- **Цитаты есть** в 100% ответов базового RAG (citation_rate 1.0); у `rag_guard` — 70%
  (в части вопросов сработал «не знаю»).
- **Смысл совпадает с цитатами**: support 0.87 (RAG) / 0.77 (RAG Guard) — судья считает
  ответы подтверждёнными цитатами. Grounding 0.50 — доля цитат, дословно совпадающих с
  чанком (модель чаще пересказывает, чем цитирует дословно).
- **Анти-галлюцинации**: `rag_guard` отказался отвечать на 2 из 10 вопросов
  (`no_answer_rate` 0.20), ценой меньшего балла (0.51 против 0.76). Off-topic вопрос
  («Как приготовить борщ?») даёт `answerable=false` с релевантностью ≈0.14.
- **Скорость**: распараллеливание прогона сократило его с ~4 минут до ~45 секунд.

**Вывод.** Источники и цитаты появились в каждом ответе, а поддержку ответа цитатами
подтверждает судья. Правило «не знаю» делает ассистента честнее: при слабом контексте он
признаётся, что не знает, вместо того чтобы сочинять.
