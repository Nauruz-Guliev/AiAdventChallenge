День 27 — Telegram-бот на локальной LLM

Встраиваем локальную модель (gemma4:12b в Ollama) в реальное приложение — Telegram-бота. Стриминг ответа, память диалога, vision, команды. Без облака.

Идея

День 26 — запустили локальную модель и общались с ней вручную. День 27 — встроить её в реальное приложение. Пользователь пишет боту в Telegram, бот идёт в локальную Ollama и показывает ответ.

Почему Telegram и long polling

Чтобы получать сообщения, бот либо ловит webhook (нужен публичный HTTPS-URL), либо сам опрашивает Telegram — long polling (публичный URL не нужен). Для локальной модели идеален long polling: всё крутится на домашнем ПК, наружу — только соединение к Telegram.

Архитектура: ядро не знает про Telegram

Telegram ⇄ aiogram (presentation) ⇄ ChatService (application) ⇄ LLMClient (port) ⇄ OllamaClient
                     │                        │
              TelegramStreamer          JsonChatStore
              (правки/сплит)            (история диалога)

Ядро зависит только от интерфейса LLMClient. Поэтому логика тестируется офлайн (FakeLLMClient), а Telegram-слой — отдельно.

Стриминг в Telegram

Ollama отдаёт ответ потоком (NDJSON: thinking + content). Telegram не умеет дописывать текст построчно, но умеет редактировать сообщение. Приём: отправляем сообщение и обновляем его (edit_message_text) не чаще ~1.2 с.

  • ответ длиннее 4096 символов → разбиваем и «переливаем» в новое сообщение;
  • Markdown → безопасный Telegram-HTML (экранирование), иначе — простым текстом;
  • «размышления» модели — по команде /think on.

Память диалога

История — на диск: data/chats/<chat_id>.json. Каждый ход в модель уходит system + последние N ходов + новый вопрос. Обрезается по числу сообщений и объёму. Для фото в истории — плейсхолдер [фото], не картинка.

Vision

Ollama принимает фото в сообщении: {"role":"user","content":"...","images":["base64"]}. Бот скачивает фото, кодирует в base64 и отправляет вместе с подписью. У gemma4:12b есть capability vision.

Если модель недоступна

Остановил Ollama → подключение падает → показываем «⚠️ локальная модель не отвечает». Заодно это наглядно доказывает, что модель работает именно локально.

.venv\Scripts\python.exe -m app.main   # long polling
