День 26 — Запуск локальной LLM

Сценарий видео · сухое, без голоса и без титров — только действия на экране

Формат. Немое видео: зритель видит терминал и браузер. Ни речи, ни плашек. Ниже — ровно то, что делаешь мышью и клавиатурой, по порядку. «Видно» — что получается в кадре само собой. Всё работает на твоём компьютере — модель `gemma4:12b` через Ollama, никакого облака и API-ключей.
  1. 0:00В терминале ввести ollama --version, затем ollama list.
    Видно: версия Ollama и локально скачанная модель gemma4:12b (8 ГБ).
  2. 0:15Запустить модель из CLI: ollama run gemma4:12b "Привет! Кто ты?".
    Видно: текст генерируется прямо в терминале — модель отвечает локально.
  3. 0:40Три запроса разной сложности через HTTP API — трижды выполнить Invoke-RestMethod -Uri http://localhost:11434/api/generate ...: «Кто ты?», «Разница между процессом и потоком», «Напиши функцию-палиндром и оцени сложность».
    Видно: три ответа — представление, объяснение, код + O(n)/O(n).
  4. 1:20Открыть чат: cd day26/chat → .\serve.ps1, браузер открывает http://localhost:8000.
    Видно: чат-страница с зелёным бейджем «ЛОКАЛЬНАЯ МОДЕЛЬ · онлайн» и баннером «все запросы идут на localhost:11434, интернет не используется».
  5. 1:40В чате задать три сообщения разной сложности (простое, среднее, сложное).
    Видно: ответ набирается посимвольно (стриминг), у каждого ответа метка «🤖 gemma4:12b · локально · N с».
  6. 2:10Показать, что это локально: нажать «Новая беседа», указать на статус «онлайн · http://localhost:11434» и баннер вверху.
    Видно: нет API-ключа, нет сетевых запросов наружу — модель отвечает с твоего же компьютера.
  7. 2:30Остановить запись.
