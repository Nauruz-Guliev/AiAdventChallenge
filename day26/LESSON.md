# День 26 — Запуск локальной LLM (урок)

## Идея

До сих пор каждый день ходил в облачное LLM API (DeepSeek). День 26 другой: мы запускаем
модель **у себя на компьютере** и общаемся с ней без облака. Это и есть «локальная LLM».

## Что такое локальная LLM

Модель (файл с весами, например `gemma4:12b` Q4_K_M, ~8 ГБ) лежит на диске и выполняется
локально — на CPU или GPU. Ничего не отправляется наружу, ключ не нужен.

| | Облако (DeepSeek) | Локальная (Ollama) |
|---|---|---|
| Где исполняется | чужие серверы | ваш компьютер |
| Нужен API-ключ | да | нет |
| Нужен интернет | да | нет |
| Скорость | зависит от сети | зависит от железа |

## Ollama

Ollama — менеджер локальных моделей. Он:

- скачивает модели (`ollama pull`);
- запускает их и держит HTTP-сервер на `http://localhost:11434`;
- даёт CLI (`ollama run`) и HTTP API (`/api/chat`, `/api/generate`, `/api/tags`, …).

## CLI vs HTTP API

```powershell
# CLI
ollama run gemma4:12b "Привет!"

# HTTP API (то же самое, но программно)
POST http://localhost:11434/api/chat
{ "model": "gemma4:12b", "messages": [{"role":"user","content":"Привет!"}] }
```

## Три запроса разной сложности

1. **Простой** — «Кто ты?» — модель представляется.
2. **Средний** — «Разница между процессом и потоком» — объяснение.
3. **Сложный** — «Функция-палиндром + сложность» — код и анализ O(n)/O(n).

## Почему нет MCP и веб-поиска

Базовая LLM — это «текст → текст». MCP и поиск — возможности **обвязки-агента**, а не модели:

- **MCP** — протокол, по которому агент подключает инструменты.
- **веб-поиск** — HTTP-инструмент, который агент вызывает.

`ollama run` или `fetch('/api/chat')` общаются с «голой» моделью, поэтому инструментов нет.
Это нормально и не «слабость» модели. Даже GPT-4 без обвязки не ищет в интернете.

Чтобы локальная модель пользовалась инструментами, её подключают как провайдера к агенту
(OpenCode, Claude Code и т.п.). Агент даёт MCP и поиск, модель — генерацию текста.

## Как воспроизвести

```powershell
ollama pull gemma4:12b                 # скачать модель (один раз)
ollama run gemma4:12b "Привет!"        # CLI

cd day26
.\demo.ps1                             # 3 запроса через HTTP API

cd day26/chat
.\serve.ps1                            # чат на http://localhost:8000
```
