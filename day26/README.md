# День 26 — Запуск локальной LLM

Запускаем локальную языковую модель через **Ollama**, обращаемся к ней через **CLI** и
**HTTP API**, делаем три запроса разной сложности и поднимаем **чат-страницу**, которая
общается с моделью напрямую на `localhost` — без облака и без API-ключей.

Стек: [Ollama](https://ollama.com) + модель `gemma4:12b` (11.9B, Q4_K_M, ~8 ГБ).
Отдельного Python-backend не нужно — сервером выступает сам Ollama (`http://localhost:11434`).

## Важно: почему локальная модель «не использует MCP и не ищет в интернете»

Базовая LLM — это просто «текст → текст». Она **не умеет**:

- обращаться к MCP-серверам — это протокол, которым пользуется **агент-обвязка**
  (OpenCode, Claude Code, Cursor), а не сама модель;
- искать в интернете — это делает HTTP-инструмент, который вызывает агент.

В задании Дня 26 MCP и веб-поиск **не требуются**. Здесь проверяется, что модель:
установлена → запускается локально → доступна по CLI/HTTP → отвечает.

Если хочется, чтобы локальная модель пользовалась инструментами — её подключают как
провайдера к агенту (например, OpenCode). Это за рамками дня.

## Проверка: 3 запроса разной сложности

| # | Уровень | Запрос | Что показал |

## Запуск

### 1. Ollama (один раз)

```powershell
ollama --version        # есть ли Ollama (нужна 0.40+)
ollama list             # какие модели скачаны
ollama pull gemma4:12b  # если модели нет — скачать
```

### 2. CLI (проверка)

```powershell
ollama run gemma4:12b "Привет! Кто ты?"
```

### 3. HTTP API — 3 запроса разной сложности

```powershell
cd day26
.\demo.ps1
```

Или вручную:

```powershell
$body = '{"model":"gemma4:12b","prompt":"Hi! What is your name?","stream":false}'
Invoke-RestMethod -Uri http://localhost:11434/api/generate -Method Post -Body $body -ContentType 'application/json'
```

### 4. Чат-страница

```powershell
cd day26/chat
.\serve.ps1            # откроет http://localhost:8000
# или вручную: python -m http.server 8000
```

> **Чат-страницу нельзя открывать двойным кликом по файлу**: с `file://` Ollama отдаёт
> 403 (CORS). Нужно подавать её с локального HTTP-сервера — тогда origin `localhost` разрешён.

## Как это работает

```
браузер (chat/index.html) ──fetch /api/chat (stream)──► Ollama (localhost:11434) ──► gemma4:12b
```

Все запросы идут на ваш компьютер. Интернет не используется.
