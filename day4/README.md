# День 4: Температура

Небольшой интерфейс для сравнения одного и того же запроса при `temperature = 0`, `0.7` и `1.2`.

## Эксперимент

Модель должна придумать пять неожиданных, но безопасных применений обычной бумажной скрепки. Для каждого варианта нужны короткое название и объяснение в одном предложении. Условие короткое, поэтому разница между осторожными и более смелыми идеями заметнее.

Каждая карточка запускается независимо. В ответе показываются:

- полный текст ответа;
- эвристическая проверка формата и запретного слова;
- поверхностные сигналы креативности и разнообразия;
- токены, время ответа и `finish_reason`.

Метрики не заменяют смысловую оценку человеком: особенно при высокой температуре нужно проверять, не потеряла ли модель условия задачи.

## Запуск

```bash
npm install
cp .env.example .env
npm start
```

Откройте http://localhost:3004.
