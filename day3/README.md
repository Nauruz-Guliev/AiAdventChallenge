# День 3: Разные способы рассуждения

Проект позволяет самостоятельно сравнить четыре способа решения одной задачи про четыре двери.

## Задача

В тёмной комнате есть четыре запертые двери, три из них ведут в стену, одна — на улицу. Есть ключ и свеча. Открыть можно только одну дверь. Нужно понять, какую выбрать, не тратя единственную попытку.

Эталонный принцип: подносить свечу по очереди к щелям или замочным скважинам, наблюдать за пламенем и выбрать дверь, у которой колебание пламени показывает поток воздуха с улицы. Дверь открывается только после проверки.

Для быстрых ответов используется более лёгкая модель `deepseek-chat`. При необходимости её можно заменить переменной `DEEPSEEK_MODEL` в `.env`.

## Четыре способа

1. **Прямой ответ** — модель получает только исходную задачу.
2. **Пошаговое решение** — в `system` message добавляется инструкция «решай пошагово».
3. **Сгенерированный промпт** — один вызов сначала проектирует промпт для решения, второй использует его.
4. **Группа экспертов** — в `system` message явно создаются аналитик, инженер и критик, после чего координатор сверяет их решения.

Отдельный верификатор не запускается: ответы и объяснения остаются на экране, а итоговую точность пользователь проверяет самостоятельно.

## Этапы интерфейса

1. Постановка задачи.
2. Четыре параллельных способа рассуждения.
3. Получение API-ответа выбранного варианта.
4. Самостоятельное сравнение результатов.

Интерфейс показывает четыре карточки решений бок о бок. У каждой карточки своя кнопка запуска. В третьей карточке одна кнопка последовательно формирует system prompt, показывает его и использует его для решения. В блоках отличий используется placeholder `[ЗАДАЧА]`, поэтому повторяющийся текст не перегружает экран. Для пошагового и экспертного вариантов прямо показывается полный `system` prompt.

## Критерии сравнения

- решение предлагает проверять двери свечой до открытия;
- ответ связывает колебание пламени с потоком воздуха;
- найденная дверь ведёт наружу;
- в ответе нет опасного совета открывать двери наугад;
- токены, reasoning-токены, `finish_reason` и время каждого выбранного вызова.

## Запуск

```bash
npm install
cp .env.example .env
npm start
```

Откройте http://localhost:3003.
