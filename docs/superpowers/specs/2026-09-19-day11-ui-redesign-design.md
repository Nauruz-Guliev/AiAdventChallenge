# Day 11 — UI-редизайн: «Разрез памяти»

Дата: 2026-09-19
Статус: утверждён (дизайн), к реализации

## Проблема

Текущий интерфейс `day11/frontend` читается как типовой тёмный SaaS-лендинг, а не как
инструмент про память:

- главный экран занят hero-заголовком и «потоком агента»; три слоя памяти зажаты
  в узкой правой колонке со вложенным скроллом;
- панель памяти стилистически чужеродна: держится на `var(--line, #2a2a35)`,
  которой в теме нет, и вводит другой оттенок и радиусы;
- в `styles.css` остался мёртвый CSS от day8–day10 (`.usage-panel`, `.facts-panel`,
  `.compare`, `.branch-tabs`, `.mode-selector`, строки ~81–205);
- кандидаты вынесены под весь воркспейс, далеко от диалога, из которого рождаются —
  связь «ответ → предложение запомнить → долговременная» не читается;
- чип токенов по слоям исчезает после рефетча чата (`ChatMessageResponse` не несёт
  `memory`);
- обобщённый вид: тёмный фон + бирюзовый акцент, ALL-CAPS кикеры, средние точки в
  мета-строках, одинаковые скруглённые карточки.

## Бриф

- Тема: три слоя памяти ассистента (краткосрочная / рабочая / долговременная).
- Зритель: проверяющий задания и сам автор.
- Задача интерфейса: за минуту показать, что память живёт в трёх **раздельных**
  слоях и что в долговременную попадает только по решению пользователя.

## Концепция

Интерфейс — **вертикальный разрез памяти**. Вертикальная ось кодирует не порядок,
а **срок жизни** записи: чем ниже, тем долговечнее. Краткосрочная — рыхлый верхний
слой, рабочая — карточка на «столе», долговременная — плотное дно из трёх ящиков.
Кандидаты стоят на **пороге** между рабочим и вечным слоем; подтверждение «погружает»
карточку в нужный ящик.

## Токены

Цвет (архивная бумага + минеральные слои; красный — строго на акте запоминания):

| Токен   | HEX       | Роль                                  |
|---------|-----------|---------------------------------------|
| paper   | `#E7E9E4` | фон                                   |
| ink     | `#171A17` | текст, фокус                          |
| mist    | `#C7D3CC` | слой краткосрочной                    |
| amber   | `#C9973B` | слой рабочей                          |
| deep    | `#23403A` | слой долговременной                   |
| stamp   | `#B23B2E` | только действие «Запомнить навсегда»  |
| line    | `#B6BDB4` | волосяные разделители                 |

Типографика: **Recursive** (одна семья, две оси — обычная для интерфейса,
`MONO` для происхождения, токенов, времени). Fallback-стек на системные. Никаких
Manrope/DM Mono. Шкала: 12 / 14 / 16 / 20 / 28 / 44. Строки < 80 символов.

## Принципы

1. **Глубина = постоянство.** Цвет и плотность слоя сообщают срок жизни.
2. **Происхождение — первого класса.** У каждой записи долговременной видно,
   из какого чата и когда она пришла (mono).
3. **Один смелый момент.** Подтверждение кандидата физически перемещает карточку
   из порога в ящик. Всё остальное — тихо.
4. **Красный штамп** — только на «Запомнить». Кандидаты — явными кнопками
   «Запомнить» / «Не надо» вместо ✅/✕.

## Раскладка (A)

```
┌───────────────────────┬──────────────────────────────┐
│ РАЗРЕЗ ПАМЯТИ         │ ДИАЛОГ                       │
│ ▒ краткосрочная ▒     │   вы: ...                    │
│   N ходов · Очистить  │   ассистент: ...             │
│───────────────────────│                              │
│ █ рабочая █           │                              │
│   цель · ограничения  │                              │
│   решения · статус    │                              │
│───────────────────────│                              │
│ ◆ ПОРОГ: кандидаты ◆  │                              │
│───────────────────────│                              │
│ ▓ долговременная ▓    │   [ поле ввода…             ] │
│   Профиль · Решения · │                              │
│   Знания (карточки)   │                              │
└───────────────────────┴──────────────────────────────┘
```

- **Мачта:** одна строка — название, одно предложение, легенда трёх слоёв. Большого
  hero нет.
- **Левая колонка «Разрез памяти»** (~420px, скролл внутри):
  - `mist` **Краткосрочная**: число ходов, «Очистить историю», мини-лента последних
    реплик, подпись «живёт только в этом чате».
  - `amber` **Рабочая**: редактируемая карточка (цель, ограничения, решения, статус),
    кнопки «Сохранить», «Завершить», «Новая задача».
  - **Порог «К подтверждению»**: очередь кандидатов.
  - `deep` **Долговременная**: три ящика (Профиль · Решения · Знания); запись —
    карточка с происхождением (mono: источник + дата) и удалением; ручное добавление.
- **Правая колонка «Диалог»**: лента сообщений, шапка с моделью, composer,
  мета-строка (модель / время / токены по слоям, mono).

## Взаимодействия

- «Запомнить» на кандидате: карточка уезжает из порога в соответствующий ящик и
  ящик подсвечивается. При `prefers-reduced-motion: reduce` — без анимации.
- «Не надо»: карточка уходит из порога.
- Разбивка токенов по слоям — в мета-строке ответа (из `response.usage.memory`),
  а не в исчезающем чипе.

## Состояния

- Пустые: у каждого слоя одна строка-приглашение («Диалог начнётся с первого
  сообщения», «Опишите текущую задачу», «Пока пусто — подтвердите кандидата или
  добавьте вручную»).
- Ошибки: карточка в ленте простыми словами; 413 → «Контекст переполнен» +
  кнопка «Начать новый чат».
- Загрузка: три точки + строка стадии в mono.

## Отзывчивость и доступность

- < 900px: одна колонка; разрез становится аккордеоном над диалогом, порог
  кандидатов — липкой панелью над полем ввода.
- Видимый фокус (ink), полная работа с клавиатуры, `prefers-reduced-motion`.
