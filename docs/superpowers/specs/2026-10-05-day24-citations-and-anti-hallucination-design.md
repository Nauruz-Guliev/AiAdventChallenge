# День 24 — Цитаты, источники и анти-галлюцинации (дизайн)

## Контекст

Продолжение RAG из Дня 23 (`day23/`): там уже есть retrieval по индексу Дня 21,
фильтр по cosine-порогу, heuristic-реранкинг и query rewrite. День 24 дорабатывает
RAG так, чтобы модель **обязательно** возвращала не только ответ, но и:

- список источников (source + section + chunk_id);
- цитаты — дословные фрагменты из найденных чанков.

Плюс правило анти-галлюцинаций: если релевантность ниже порога — ассистент обязан
сказать «не знаю» и попросить уточнение.

## Объём

Новая папка `day24/` = копия `day23/` (backend + frontend + настройки). Индекс — тот же,
из `day21/index/structure.json`. LLM — DeepSeek, эмбеддинги — sentence-transformer.

## Режимы

- `no_rag` — чистый LLM, без источников и цитат (как в Дне 23).
- `rag` — базовый RAG (retrieval → контекст → LLM), теперь **с цитатами**.
- `rag_guard` — полный пайплайн (query rewrite + фильтр + heuristic-реранкинг) +
  цитаты + **правило «не знаю»**.

## Модель данных

`Hit` не меняется. Добавляются:

```python
@dataclass(frozen=True)
class Citation:
    ref: int          # номер [n] в ответе
    chunk_id: str
    source: str
    section: str
    quote: str        # дословный фрагмент из чанка
    grounded: bool    # True, если quote — подстрока чанка (≥ min_quote_len)

@dataclass(frozen=True)
class Answer:
    mode: Mode
    text: str
    sources: tuple[Hit, ...]
    citations: tuple[Citation, ...]
    answerable: bool = True        # False → «не знаю»
    relevance: float | None = None # max скор топ-чанка (rag_guard)
```

`Mode = Literal["no_rag", "rag", "rag_guard"]`.

## Пайплайн цитат

1. RAG-промпт (общий для `rag` и `rag_guard`): «Отвечай на вопрос по приведённому
   контексту. Каждый факт помечай ссылкой `[n]` на номер блока контекста. Не ссылайся
   на блоки, из которых не берёшь факт.»
2. Контекст — пронумерованные блоки `[1] source :: section\n<текст>`.
3. После ответа LLM backend:
   - парсит маркеры `\[(\d+)\]` в порядке появления;
   - для каждого уникального `n` (1-based) берёт чанк `hits[n-1]` и ищет **самую
     длинную общую подстроку** (LCS) между текстом ответа и текстом чанка;
   - если длина ≥ `min_quote_len` (24 симв.) — цитата `grounded=True` (дословный
     «фрагмент из чанка» по построению), иначе `grounded=False` (модель сослалась,
     но не воспроизвела слова чанка — признак галлюцинации).

LCS-извлечение гарантирует: каждая «цитата» — реальный фрагмент чанка, а признак
`grounded` показывает, нашлось ли вообще дословное совпадение.

## Анти-галлюцинации («совпадает ли смысл ответа с цитатами»)

Два уровня:

- **Механика** — `grounding_rate` = доля цитат с `grounded=True`.
- **LLM-судья поддержки** — судья получает (вопрос, ответ, список цитат) и возвращает
  `support_score` 0…1 («подтверждают ли цитаты ответ»). Парсинг — как у основного судьи.

## Правило «не знаю» (только `rag_guard`)

После retrieval + реранка считаем `relevance = max(h.score for h in hits)` (финальный
скор лучшего чанка). Если хитов нет **или** `relevance < no_answer_min_score`
(по умолчанию `0.50`) → возвращаем фиксированный текст:

> Я не нашёл достаточно релевантного материала, чтобы ответить. Уточните, пожалуйста, вопрос.

с пустыми `sources`/`citations`, `answerable=False`, `relevance` = фактическое значение,
**без вызова LLM**.

## Оценка на 10 вопросах

`eval_questions.json` — те же 10 KMP-вопросов из Дня 23. Для каждого ответа (по режимам)
считаем:

- `has_sources` — список источников непуст;
- `has_citations` — есть хотя бы одна grounded-цитата;
- `grounding_rate` — доля grounded-цитат;
- `support_score` — LLM-судья поддержки.

Сводка по режиму: `avg_score` (как в Дне 23), `source_coverage_rate`, `citation_rate`,
`avg_grounding`, `avg_support`, `no_answer_rate` (для `rag_guard`).

Демонстрация «не знаю» — отдельно, 2 off-topic вопроса («Как приготовить борщ?»,
«Что такое React hooks?») через UI и smoke-скрипт: там `answerable=False`.

## Настройки

В `settings.py` (и `.env.example`):

- `min_quote_len` = 24 (мин. длина grounded-цитаты);
- `no_answer_min_score` = 0.50 (порог «не знаю»).

## API / фронтенд

- `CitationSchema` = {ref, chunk_id, source, section, quote, grounded}.
- `AnswerSchema` += {citations, answerable, relevance}.
- `ModesResponse` — `modes: {no_rag, rag, rag_guard}`.
- `AnswerPanel` — рендер цитат (фрагмент + источник::секция + chunk_id), состояние
  «Не знаю», значение relevance.
- `CompareTable` — новые колонки: цитаты есть / grounding / support.
- `App` — заголовок «Цитаты, источники и анти-галлюцинации».

## Тесты

FakeLLM генерит ответы с маркерами `[1]`, `[2]`. Покрытие:

- парсинг маркеров и разрешение в чанки;
- LCS-извлечение цитат (короткое/длинное совпадение);
- `grounded` при отсутствии дословного пересечения;
- guard «не знаю» (нет хитов / низкий скор);
- схемы ответа и сводки.

Все тесты офлайн, ожидание — зелёный `pytest`.

## Вне области

- Cross-encoder реранкинг, гибридный BM25-поиск, расширение контекста соседними чанками
  — не входят в День 24.
